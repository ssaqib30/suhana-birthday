HOW TO USE:
1. Open index.html on your computer to preview it.
2. To give Suhana a real link, upload the whole folder to a static website host.
3. GitHub Pages is a simple free option:
   - Create a GitHub repository.
   - Upload index.html and the photos folder.
   - Settings -> Pages -> Deploy from branch -> main / root.
   - GitHub will give you a public link.
4. Send that link to Suhana.
